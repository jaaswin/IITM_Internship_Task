# Internship Tasks @ IITM-CC

This repository contains the implementation and documentation of three internship tasks completed at the **P.G. Senapathy Centre for Computing Resources, IIT Madras**.

## Task 1 – DHCP Configuration & Automation

Implemented and tested a DHCP server in a Linux environment.

**Key areas:**

* DHCP server installation and configuration
* Dynamic IP address allocation
* MAC-based IP reservation
* ISC DHCP configuration
* Kea DHCP migration concepts
* Kea Control Agent and REST API
* Python-based DHCP reservation automation

The DHCP server and client communication were successfully tested. 

## Task 2 – DNS Server Configuration

Configured and tested a DNS server in a Linux environment.

**Key areas:**

* DNS server installation
* DNS configuration
* Domain name and IP address resolution
* DNS records and A records
* Client-side DNS testing
* `ping` and `nslookup` verification

The DNS resolution was successfully verified from the client system.  

## Task 3 – DDoS / Excessive-Traffic Detection & Mitigation

Developed a controlled cybersecurity laboratory using Docker to demonstrate excessive HTTP traffic detection and mitigation.

**Key areas:**

* Docker-based three-machine environment
* Secure file-upload service
* HTTP request monitoring
* IDS-style alert generation
* Rate limiting using Flask-Limiter
* HTTP 429 mitigation
* Verification of legitimate traffic after mitigation

The experiment was conducted in a private Docker environment as a controlled excessive-traffic/DoS simulation. 

## Technologies Used

`Linux` · `DHCP` · `DNS` · `Kea` · `Python` · `Docker` · `Docker Compose` · `Flask` · `Flask-Limiter` · `REST API` · `VirtualBox`



**Purpose:** This repository documents my practical experience in **network configuration, network services, automation, and cybersecurity monitoring/mitigation**.
